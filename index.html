WER FÄNGT AN?

Jeder wirft auf das Bull. Wer am nächsten liegt, beginnt. Bei Gleichstand erneut werfen.

Start mit 0 Herzen. Eigene Zahl: Single +1, Double +2, Triple +3, maximal 3 Herzen. Mit 3 Herzen bist du Killer. Gegnerische Killer ziehen Herzen ab. Bei einem Angriff auf 0 Herzen scheidest du aus; die 0 Herzen am Start allein eliminieren dich nicht.
HOW TO PLAY

Killer. Einfach erklärt.

  1. Starte bei null. Alle starten mit 0 von 3 Herzen und sind im Spiel.
  2. Baue Herzen auf. Triff deine eigene Zahl: Single +1, Double +2, Triple +3. Herzen bleiben über Runden erhalten; maximal 3.
  3. Volle Herzen = Killer. Mit 3 Herzen kannst du Gegner angreifen: Single −1, Double −2, Triple −3. Nach Herzverlust füllst du dein eigenes Feld wieder auf.
  4. Null nach einem Angriff = raus. Ausgeschiedene Spieler können nicht zurückkehren. Wer als Letzter übrig bleibt, gewinnt.

Die eigene Zahl baut immer Herzen auf, bis maximal 3. Daneben, Bull und unbelegte Felder haben keinen Effekt. Pro Aufnahme hast du drei Darts.
